# OpenJOC 0.6.1 backport plan

This plan is intentionally separate from release execution. It does not create
a release branch, change the package version, tag, push, or publish anything.

## Release boundary

The released baseline is `v0.6.0` at `5292d00`. Current development HEAD is
the 0.7 integration line and contains the embeddable session, C ABI, shared
session CLI path, and deterministic dither-state retention. Those integration
foundation changes must not enter the 0.6.1 hotfix.

## Backport safety

The downmix mathematics is isolated in `openjoc-eac3` and has no dependency on
the 0.7 integration crates. The whole development-line fix commit is not a
blind cherry-pick candidate because its API hunk targets `openjoc-api`, which
does not exist at the `v0.6.0` baseline. The safe 0.6.1 recipe is:

1. Start `release/0.6` at `v0.6.0`.
2. Cherry-pick `1c6dbce`.
3. Reapply the overload fix as a minimal 0.6 patch: add the shared
   `openjoc-eac3` matrix module/export, replace the 0.6 CLI's duplicate raw
   downmix equations with that matrix, and carry the analytical matrix/LFE
   regressions.
4. Carry only the downmix documentation needed for the 0.6.1 behavior.
5. Do not add `openjoc-api`, `openjoc-capi`, session packet changes, dither
   integration changes, or any other 0.7 foundation code.

The resulting hotfix branch should contain only the two correctness changes:
the 2.0 spatial-projection repair and the 2.0 downmix overload-protection
repair. Versioning to `0.6.1`, tagging `v0.6.1`, pushing, and publishing remain
future release actions requiring separate authorization.

## Validation to repeat on the hotfix branch

- Analytical Lo/Ro and Lt/Rt coherent full-scale matrix fixtures.
- Auto-to-selected-policy equivalence, DRC policy × downmix smoke coverage,
  metadata-gated LFE coverage, and Base/RB/FULL contribution linearity.
- Existing 5.1, 7.1.4, and binaural regressions.
- `cargo fmt --all -- --check`, workspace check/clippy/tests, and release build.
- Manual real-media validation with `--downmix auto`, `--downmix loro`, and
  `--downmix ltrt`.
