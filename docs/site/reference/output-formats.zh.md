# 输出格式

OpenJOC 会把渲染语义和容器语义分开处理。所选输出扩展名决定容器格式，但不会改变已经渲染出的 PCM。

扬声器布局渲染同时支持用 `.wav` 和 `.caf` 输出 `22.2`。两种容器用不同方式记录声道身份：

| 布局 | WAV（`.wav`） | CAF（`.caf`） |
| --- | --- | --- |
| 可由 WAVEFORMATEXTENSIBLE 掩码表示的标准预设 | 提供真实的 `WAVEFORMATEXTENSIBLE` 声道身份和掩码。 | 语义声道标签。 |
| `7.1.6` 或 `9.1.x` | 拒绝写入。 | 语义声道标签。 |
| `22.2` | 按 canonical 顺序写入显式无掩码的 24 声道 PCM。 | 语义化输出：用标准 CAF 声道标签表示可命名声道，用坐标描述表示其余位置，完整保存 22.2 声道身份。 |
| 自定义布局 | 按声明顺序写入显式无掩码 PCM。 | 保留语义声道描述；自定义几何使用坐标描述。 |

| 其他输出 | 约定 |
| --- | --- |
| 双耳输出 | 双声道、分别对应左右耳的输出。 |
| `export-adm` 输出 `.wav` / `.bw64` | 带有符号 24 位 PCM 和同目录 JSON 报告的重建 ADM BWF 文件。 |

LFE 声道是逻辑上的输出目的地，不是投影顶点；OpenJOC 不执行分频或低频管理。

## 电平与延迟

推荐的渲染顺序是：

```text
编码后的 DRC → 节目 Dialnorm → JOC 渲染
  → 扬声器 FinalLinkedGain → 可选的静态峰值缩放 → 文件
```

扬声器输出会报告 609 个采样点的可用性延迟。使用内置 HRIR 或 48 kHz 自定义 SOFA 时，双耳输出报告 577 个采样点；其他采样率的自定义 SOFA 会再加上转换滤波器的公共因果延迟。源文件的 `Data.Delay` 和有限长度的 FIR 尾部不计入报告值。逻辑 PTS 不会为了隐藏这个延迟而移动。

`export-adm` 会一直以浮点形式保留重建结果，直到进入整数边界。它的有符号 24 位写入器遇到非有限值或超出范围的采样值时会拒绝写入，而不是裁剪、归一化或悄悄衰减。请参阅[PCM24 余量](../compatibility/pcm24-headroom.md)。
