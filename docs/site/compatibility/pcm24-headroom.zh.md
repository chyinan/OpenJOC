# PCM24 余量

JOC 重建使用浮点数完成。在写入文件并量化之前，一个合法的重建采样值可能超出归一化的有符号 24 位范围。

        ≠

## 导出策略

如果采样值不是有限值，或超出有符号 24 位范围，ADM 导出器会拒绝写入。它不会：

- 裁剪或饱和；
- 对单个对象或轨道做归一化；
- 擅自套用隐藏的限幅器；
- 悄悄降低整个节目的音量。

导出成功时，同目录的 ADM 报告会提供一份受限的余量统计，包括整个节目和各路信号的统计数据。

这项策略是为了保护输出的含义。真实素材出现余量问题，并不一定说明解码器失败；它说明合法的浮点重建结果无法在所选整数容器中表示，而导出器有意不替用户臆造一个处理策略。

如果需要浮点格式的扬声器或双耳文件，请使用 WAV/CAF 渲染流程。如果需要重建 ADM，应把范围错误当作需要处理的导出决策，而不是把它理解成可以直接裁剪的许可。
