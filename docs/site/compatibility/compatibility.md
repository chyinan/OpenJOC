# Compatibility

OpenJOC separates “can produce this output” from “has been validated with this host, device, or renderer.”

The current positive surface includes bounded raw E-AC-3 and seekable ordinary MP4/M4A workflows, the documented speaker presets, custom layouts, virtual-speaker binaural output, the scoped reconstructed ADM path, and project-provided framework integrations.

The current non-claims include original authored-object identity, original ADM-master recovery, native Dolby renderer fidelity, automatic physical-device layout discovery, and universal hardware playback.
