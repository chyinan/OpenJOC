# Standards and references

OpenJOC's public ADM and container interoperability work is grounded in the following references. The project does not copy private vendor implementation details into the repository or site.

- [ITU-R BS.2076](https://www.itu.int/rec/R-REC-BS.2076/) — Audio Definition Model.
- [ITU-R BS.2088-2](https://www.itu.int/dms_pubrec/itu-r/rec/bs/R-REC-BS.2088-2-202511-I!!PDF-E.pdf) — long-form WAVE metadata chunks and size semantics.
- [Dolby Atmos Master ADM Profile v1.0](https://developer.dolby.com/globalassets/documentation/technology/dolby_atmos_master_adm_profile_v1.0.pdf) — profile relationships and interoperability constraints.
- [EBU Tech 3285 Supplement 6](https://tech.ebu.ch/publications/tech3285s6) — public `dbmd` envelope semantics.
- [EBU Tech 3285 Supplement 7](https://tech.ebu.ch/publications/tech3285s7) — `chna` chunk reference semantics.
- ETSI TS 103 420 and TS 103 190-2 — the public E-AC-3 JOC and OAMD syntax subset recorded by the implementation provenance.

The [reconstructed ADM export](../using/reconstructed-adm-export.md) documents which portions are used for the current writer and validator. The [clean-room methodology](clean-room-methodology.md) documents the evidence classes and prohibited implementation sources.
