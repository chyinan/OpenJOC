# Historical documentation archive

Files below this directory preserve release contracts or evidence that remains
useful but does not describe current OpenJOC behavior.

- [`releases/`](releases/) — version-specific acceptance and release notes.
- [`requirements/`](requirements/) — historical requirement/evidence matrices.

For current truth, start with [Capabilities](../CAPABILITIES.md),
[Known limitations](../KNOWN_LIMITATIONS.md), and the
[documentation index](../README.md). Release chronology belongs to the
[CHANGELOG](../../CHANGELOG.md).
