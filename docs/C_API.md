# C ABI

The canonical C ABI guide is maintained in the [OpenJOC documentation site](site/reference/c-abi.md).

The ABI is `1.7-experimental`; the versioned interface uses opaque handles,
bounded stream decoding, and an explicit opt-in pull surface for
device-independent 3DoF listener orientation. See the canonical guide for
threading, ownership, limits, and evidence boundaries.

This repository path is retained as a short compatibility pointer for existing links.
