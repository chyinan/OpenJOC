# J2R13 N3 Producer Export Execution

J2R13 recorded one producer-side invocation for the authorized first run. The
resolved destination did not match the approved destination binding, so the
resulting partial file was quarantined and excluded from scientific admission.

The consumed run and nonce were terminalized. The remaining queue was stopped;
no other producer run was executed. The event therefore supplies no N3 carrier
evidence and does not change `SemanticBindingState::Unresolved`.

J2R14 replaces the retired queue with a fresh recovery namespace and validates
the parent-plus-leaf destination contract using non-media tests and cancel-only
Logic rehearsals. The quarantined artifact remains private and hash-frozen.
