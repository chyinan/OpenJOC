# J3R9 — bounded output discovery realm

**Decision:** `N3_BOUNDED_POST_EXPORT_DISCOVERY_REALM_ADMITTED`

J3R9 closes the destination-provenance problem without treating the Logic save
panel's selected parent as scientific evidence.  A fresh, disposable S_FL
project was opened in a fresh Logic process.  Before the single final action,
the controller froze an exact 128-bit output stem, the final-leaf grammar,
private discovery realm, forbidden-subtree policy, zero-match preflight,
process tuple, project identity, and DD+ Atmos / Music / 768 kbps / Project /
ADM-off settings.  It then durably consumed one nonce and allowed exactly one
final UI action.

The producer created exactly one matching final leaf after invocation.  It was
inside the frozen private realm and outside every forbidden subtree.  Its
original parent, size, SHA-256, process tuple, invocation timing, and realm
hash were frozen before any subsequent handling.  A bounded structural smoke
check recognized an MP4 carrier containing 48 kHz E-AC-3.

This admits the *destination contract*, not scientific media evidence.  The
probe remains `CONTROLLER_PROBE_ONLY` and is excluded from the N3 replacement
queue, null/repeatability claims, C1/C2/C3, semantic binding, object identity,
and renderer work.  Synthetic non-media tests lock rejection of outside-realm,
forbidden-subtree, pre-existing, duplicate, wrong-suffix, and post-authorization
realm-mutation cases.

Future replacement runs may use this exact model: a unique high-entropy stem,
the same frozen private realm and forbidden subtrees, pre-invocation absence,
one nonce-bound invocation, one in-realm final leaf, and original-path
attestation before any canonical move.  `SemanticBindingState::Unresolved`
remains mandatory; no decoder, warp, or vendor semantic rule changed.
