# Engineering planning records

This directory contains temporary design and implementation plans used to
organize repository work. It is separate from `docs/` and is not included in
the published MkDocs site.

User-facing explanations belong under `docs/site/`. Historical plans remain
here as engineering records and should not be treated as current product
documentation.

- `design-plans/` — design records;
- `implementation-plans/` — phase plans and test requirements.
